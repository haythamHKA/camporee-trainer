# Camporee Skills Trainer

A practice tool for Troop 321G's patrols, made for the 8th Annual Girl Camporee of the East Coast, "Back to the Future".

Tap a station on the map. Each of the six stations has three parts:
- Name It: flashcards for the gear
- Build It: animated steps and a practice clock
- Test Yourself: a 17-question quiz with answers explained

Works on phones and computers, with no app to install.
Built from the 2026 Leader Guide. Practice drawings only, not photos.
